# EdgeCenter V2 — Инфраструктура для больших идей

## Основная идея

Масштаб ощущается через связь. Три отдельных технологических модуля становятся одной архитектурой вокруг идеи клиента. Посетитель может разобрать эту архитектуру, понять назначение каждой части и собрать её обратно.

Слоган: **«Инфраструктура для больших идей».**

## Что взято из исследования Spline

В авторизованном каталоге `https://app.spline.design/templates` исследована подборка стеклянных сцен и интерактивных компонентов: Glass Effect, Glass Circles, Glass Type, 3D Paths Glass Fluid, Liquid Glass UI. Открыта копия Glass Effect для изучения многослойной прозрачности и освещения.

Для EdgeCenter создана собственная сцена через Spline MCP. Из шаблонов заимствован принцип работы стекла, света и слоя, а форма продолжает три соединённые рамки из предыдущего сайта и фильма. Скачивание готового чужого макета не потребовалось.

## Визуальный язык

- Серебро: облачные вычисления, мощность, инженерная точность.
- Тёмно-синий металл: CDN, связность, сеть доставки.
- Аквамариновое матовое стекло: защита, прозрачность и уверенность.
- Светящееся ядро: идея клиента в центре системы.
- Голос бренда: короткие глаголы — вычислять, приближать, защищать.
- Основная типографика: локальный Golos, крупный спокойный заголовок, простые русские подписи.
- Цвета интерфейса: #132548, #2455EB, #E4EAF0, белый; аквамарин служит сигналом, а не фоновым украшением.

## Сцена и взаимодействие

38 объектов, включая три составных рамки, вычислительные блоки, орбиты, щит, два источника света и плоскость теней. Авторские скруглённые mesh-рамки, общие материалы, HDRI-освещение и настоящий transmission/glass-слой Spline.

Пять положений: вся система, облако, CDN, защита, разбор на три модуля. Смена положения занимает 850 мс с плавным замедлением. Один управляющий цикл работает только во время перехода. При повторном нажатии переход продолжается от текущей позы, без скачка назад. Reduced motion обнуляет длительность.

Поворот мышью помогает рассмотреть форму. На телефоне сохраняется прокрутка страницы, а 3D запускается по нажатию. Одна сцена на странице; невидимые сцены не продолжают рендериться.

## Экспорт

Editable Spline file: `145279db-c669-4841-9b93-72b78eb5a903`.

Code export: `https://prod.spline.design/HzWQivzCRnwA3ohb/scene.splinecode`.

В сайт включена локальная копия экспорта и закреплённая версия `@splinetool/runtime`. Оверлей управления из `src/spline/interaction.html` входит в сам экспорт. Кнопки сайта могут передавать только разрешённые режимы через типизированные сообщения; выполнение произвольного кода через сообщения не поддерживается.

Документация: https://docs.spline.design/exporting-your-scene/web/exporting-as-code

## Продолжение концепции

Первый экран сменяется связной историей трёх продуктов. Затем пользователь выбирает задачу, исследует услуги или переходит в отраслевое решение. Продуктовые страницы начинают с соответствующего 3D-модуля и продолжаются функциональными демонстрациями. Общая система навигации объединяет 24 страницы.

Брендбук и фильм из V1 сохранены. Эта версия развивает интерактивное поведение сайта; отдельный новый фильм не создавался.
