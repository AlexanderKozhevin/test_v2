# EdgeCenter / Spline reference library

Исследование от 9 сентября 2026. Цель — развить светлую концепцию EdgeCenter через реальные материалы и взаимодействия Spline, сохранив три силы: вычисления, доставка, защита.

## Результат и границы проверки

- 38 работ отобраны с главной Community и через запросы glass, abstract, cloud. Все 38 превью открыты и визуально просмотрены.
- 10 страниц подробно проверены: автор, описание, ссылка на сцену и ссылка на лицензию CC BY 4.0.
- 7 настоящих сцен открыты и визуально просмотрены: Stackable Glass, Prism, Boxes Hover, Clarity Stream, WEB Diagram, Liquid Glass Switcher, Abstract 3D Icon Set. Это проверка реального рендера, не полноценный аудит всех событий.
- У Stackable Glass создан рабочий ремикс, прочитаны слои и параметры; получен настоящий Hana iframe / scene.hanacode.
- `index.html` — каталог с фильтрами, поиском, приоритетом, назначением и ссылками.
- `study.html` — отдельный стенд с экспортом ремикса. Загрузка по кнопке; остановка удаляет iframe. Исходная геометрия и цвета сохранены, чтобы оценивать материал без подмены.
- Сцена главного сайта пока не заменена. Старые экспериментальные файлы 3D не входят в публикацию библиотеки.

Это тематическая выборка, не полный обход всего Community. «Основа» означает перспективный исходник для адаптации, а не готовность к продакшену.

## Выбор для концепции

| Продукт / слой | Источники | Что переносим |
|---|---|---|
| Главный объект | Stackable Glass + пользовательский 3D Design Text | Прозрачные перекрывающиеся оболочки, отдельные кромки света/тени, стекло с читаемой толщиной |
| Облако | Interactive AI website + Boxes Hover | Ритм модулей, локальные состояния, связь количества блоков с масштабом |
| CDN | Clarity Stream + Holographic Earth | Трассы и направление потока, понятные связи между точками |
| Защита | Prism + Stackable Glass | Защитная линза вокруг содержимого, преломление и прозрачность |
| Общая платформа | WEB Diagram | Изометрические продуктовые узлы и соединения; заменить чужие знаки своими |
| Материал карточек | Abstract 3D Icon Set | Единая камера, скругления и семейство материалов; упростить фактуру |
| Управление | Liquid Glass Switcher | Стеклянный бегунок и ясное активное состояние |

Светлая палитра первого сайта остаётся основой. На главном объекте нужны серебро, глубокий синий и холодное полупрозрачное стекло. Хроматика применяется к граням, а не ко всему экрану. Вместо постоянного вращения — спокойная исходная поза и реакция на действия.

## Рецепт 1: Stackable Glass — прочитано в редакторе

Автор: [Spline Team / spline](https://community.spline.design/@spline).
[Источник](https://community.spline.design/file/12c88eab-fad8-4360-bf1d-1c951436188d), [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/).
[Рабочая копия](https://app.spline.design/ui/3b37d2f7-9804-44e6-9493-fc20fab4a31a).

Структура: белый Frame 1024 × 700 → Group → Rectangle 4, Rectangle 3, Rectangle 2, Rectangle. Передний Rectangle 4: 190 × 300, Corner 55, Position 66 / −85.50.

Слои Rectangle 4:

1. Color #6785FF, opacity 20%.
2. Inner Shadow: X 1, Y −1, Blur 2, #FFFFFF / 40%.
3. Inner Shadow: X 0, Y 1, Blur 2, #000000 / 10%.
4. Liquid Glass: Offset 0 / 0, Distortion 36, Depth 29, Blur 0, Aberration 0 (Edge), Profile 0, Magnification −100.
5. Event Look At присутствует; параметры события ещё не разобраны.

Вывод: выразительность здесь не зависит от сильной хроматической аберрации. Сначала работают перекрытие слоёв, фон под стеклом и две кромки.

Экспорт из UI:

```html
<iframe src="https://my.spline.design/stackableglass-arMRnqvjXHJilc5liC3wkB77-xrP/"
  title="Stackable Glass" width="100%" height="100%" style="border:0"></iframe>
```

Альтернативный код, показанный самим редактором:

```html

<hana-viewer url="https://prod.spline.design/kOhcdQ5Qe2y2W21p-adr/scene.hanacode"></hana-viewer>
```

В стенде проверяется iframe-вариант; альтернативный viewer отдельно не тестировался.

## Рецепт 2: пользовательский 3D Design Text

[Исходник пользователя](https://app.spline.design/ui/3248ca86-de5d-4946-8a68-d854192aa13d), «3D Design Text - Copy - Copy».

Прочитано в Hana: Text 2 в интерактивном фрейме. Эффекты 3D Shape + Drop Shadow. У материала принципиально другие настройки, чем у ранних экспериментальных рамок сайта.

| Параметр | Значение UI |
|---|---:|
| Depth | 38.30 |
| Bevel / профиль / sides | 2.92 / Round / 3 |
| Smooth Angle / Subdivision | 40 / 12 |
| Roughness / Metalness | 0.14 / 0.16 |
| Reflectivity | 2.89 |
| Glass | 1 |
| Aberration | 14 |
| Thickness / Refraction | 2.20 / 1.07 |
| Blur | 6.15 |
| Environment | Blue photo studio |
| Exposure / Rotation Y | 1 / 4.06 |
| Light intensity | 119.50 |
| Ambient | 0.75, white |
| Light height / direction | 131 / 305 |
| Cast Shadows | No |
| Fresnel | Disabled |

Единицы Rotation Y здесь не интерпретируются: записано значение интерфейса. Drop Shadow присутствует, но его параметры не считаны. Есть Base State, State и Mouse Hover. Эти значения относятся к Hana 3D Shape; их нельзя автоматически переносить один к одному в классический Spline 3D runtime.

## Наблюдения по реальным сценам

- Prism: рифление действительно искажает объект за стеклом; смысловой приём сильный. Исходный hero при viewport 1100 × 720 обрезает крупную типографику. Переносить материал, верстать текст сайта отдельно.
- Boxes Hover: в начальной позе сцена почти пустая. Нельзя полагаться только на hover для первого впечатления и мобильного показа.
- Clarity Stream: реальные тонкие линии формируют широкую волну; подходит как мотив доставки между разделами, но требует смены тёмного фона.
- WEB Diagram: уже в спокойной позе читаются отдельные узлы с полупрозрачными подставками. Полезная визуальная грамматика для трёх сил.
- Liquid Glass Switcher: реальный рендер показывает мягкую объёмную кромку, тень и отдельный бегунок. Состояние Work отличается от превью Sleep — статичная обложка не описывает весь объект.
- Abstract 3D Icon Set: материал в реальном рендере заметно зернистый. Не переносить шум без проверки на Retina и в маленьком размере.

## Переиспользование и проверка

Сохранять атрибуцию: название работы, автор, URL, CC BY 4.0, описание собственных изменений. У остальных 28 работ условия ещё не проверены; отметка об этом есть в каталоге. У Chromatic abstract shapes описание дополнительно ссылается на платный полный пак — это не разрешение забирать весь пак.

Перед заменой главной сцены: адаптировать геометрию и цвета; сравнить с первым светлым макетом; проверить совпадение фона, толщину стекла и тени, устойчивость изображения в покое, поведение drag / touch, размер загрузки и reduced motion. Не подменять эту проверку успешной сборкой.

## Поддержка библиотеки

- `sources.json` — основной каталог, содержит собственные заметки и назначение.
- `inspection.json` — компактная запись проверенных авторов, лицензий и URL сцен.
- `seed-ids.txt` — ID исходников.
- `collect.py` — обновление публичных метаданных с сохранением собственных аннотаций.
- `build_gallery.py` — повторная сборка HTML из JSON.

```sh
python3 reference-library/spline/collect.py
python3 reference-library/spline/build_gallery.py
```
